# M0 — Foundations

**Goal:** a repository where every standard in `docs/standards/` is enforced by a tool, and a
first release tagged by CI.

## Tasks

- [x] Standards and tooling extracted into a reusable template: `wghami/python-project-standards`
      (Copier template + `standards` CLI); the project tracks its latest release.
- [x] Project rendered from the template; `.copier-answers.yml` pins the release.
- [x] Package skeleton `myenergie` with the layers of SPEC §8 and their import contracts.
- [x] Project-specific standards: architecture, simulation, security (`docs/standards/project/`).
- [x] ADRs 0002 (dishka), 0003 (decisions are policies), 0004 (SmartMDAO rule disciplines).
- [x] Public GitHub repository, CI green, rulesets on `main` and release tags, Pages enabled.
- [x] First release `v0.1.0` tagged by the release job.
- [x] Template update loop proven: drift detected, `copier update` to v0.1.2 merged by PR.

## Acceptance criteria

- `uv run pre-commit run --all-files --hook-stage pre-push` passes locally.
- Every CI job is green on `main`; `main` accepts changes only through PRs with green checks.
- `v0.1.0` exists on GitHub with wheel, sdist, SBOM and provenance.
